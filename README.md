## Описание

Эмулятор UNIX-подобной командной строки с виртуальной файловой системой (VFS) на JSON.

## Этап 1. REPL

- Консольный интерфейс (CLI)
- Приглашение содержит имя VFS
- Парсер с раскрытием переменных окружения ($HOME)
- Команды-заглушки `ls`, `cd`
- Команда `exit`
- Обработка ошибок

## Запуск

    python src/main.py
