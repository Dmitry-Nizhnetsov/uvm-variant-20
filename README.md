## Этап 1. REPL

Реализован минимальный прототип:

- Консольный интерфейс (CLI).
- Приглашение содержит имя VFS.
- Парсер с раскрытием переменных окружения (`$HOME`, `$USER`).
- Команды-заглушки `ls`, `cd`.
- Команда `exit`.
- Обработка ошибок неизвестных команд.

---

## Этап 2. Конфигурация

Добавлены:

- **Параметры командной строки:** `--vfs`, `--script`, `--config`.
- **YAML-конфиг** с полями `vfs_path` и `startup_script`.
- **Логика приоритета:** значения из YAML важнее значений из CLI.
- **Отладочный вывод** всех параметров при запуске.
- **Стартовый скрипт** — выполняется при запуске, останавливается при первой ошибке, выводит и ввод, и вывод (имитация диалога).
- **Обработка ошибок** чтения конфига и отсутствия файлов.
- **Скрипты реальной ОС** (bash) для тестирования разных VFS.

## Установка

```bash
git clone https://github.com/Dmitry-Nizhnetsov/shell-emulator.git
cd shell-emulator
pip install -r requirements.txt
```

---

## Запуск

### Через YAML-конфиг

```bash
python3 src/main.py --config config.yaml
```

### С указанием VFS

```bash
python3 src/main.py --vfs vfs/few_files.json
```

### Со стартовым скриптом

```bash
python3 src/main.py --vfs vfs/few_files.json --script scripts/test_all.txt
```

### Через скрипт реальной ОС

```bash
./os_scripts/run_few_files.sh
```

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs <path>` | Путь к JSON-файлу виртуальной файловой системы |
| `--script <path>` | Путь к стартовому скрипту (выполняется при запуске) |
| `--config <path>` | Путь к YAML-конфигу |

**Логика приоритетов:** значения из YAML-конфига имеют приоритет над значениями из командной строки.

---

## Конфигурационный файл

Формат YAML. Пример `config.yaml`:

```yaml
vfs_path: vfs/few_files.json
startup_script: scripts/test_all.txt
```

Поддерживаемые поля:

- `vfs_path` — путь к VFS;
- `startup_script` — путь к стартовому скрипту.

Если конфиг не найден или содержит ошибки — выводится сообщение, программа продолжает работу с параметрами из CLI.

---

## Стартовые скрипты

Файл с командами эмулятора, по одной в строке.

- Строки, начинающиеся с `#`, игнорируются.
- Пустые строки пропускаются.
- **При первой ошибке выполнение останавливается.**
- На экран выводится и ввод, и вывод.

Пример `scripts/test_all.txt`:

```
# Тестирование команд (этап 2)
ls
cd docs
ls
cd ..
exit
```

---

## Скрипты реальной ОС

Скрипты в папке `os_scripts/` запускают эмулятор с разными VFS:

- `run_minimal.sh` — минимальная VFS (`vfs/minimal.json`);
- `run_few_files.sh` — несколько файлов (`vfs/few_files.json`);
- `run_deep.sh` — глубокая иерархия (`vfs/deep_tree.json`).

Запуск:

```bash
chmod +x os_scripts/*.sh
./os_scripts/run_few_files.sh
```
